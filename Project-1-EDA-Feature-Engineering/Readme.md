## 🧠 What’s This?

A data prep powerhouse that takes raw e‑commerce data and turns it into **ML‑ready gold**.  
We clean, transform, and engineer features so your models can actually perform.

---

## ⚡ Quick Wins

- ✅ **Missing data?** Handled (median imputation + KNN demo)  
- ✅ **Outliers?** Capped with IQR (no data loss)  
- ✅ **New features?** 8 of ’em – day of week, weekend flag, discount codes, avg item value & more  
- ✅ **Categoricals?** One‑hot encoded  
- ✅ **Multicollinearity?** Checked & auto‑dropped  
- ✅ **Scaling?** StandardScaler applied  

---

## 🛠️ Tech Stack

- Python 3.8+  
- Pandas, NumPy, SciPy  
- scikit‑learn (KNNImputer, StandardScaler)

## 🚀 How to Run

1. Place your Excel file at the path specified in the script.  
2. Run `Project1-DecodeLabs.py`.  
3. Grab your processed CSV from the `output/` folder.
